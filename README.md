WhatsApp Chat Analyzer

A Python-based AI/NLP project that analyzes exported WhatsApp group chats and generates useful insights, analytics, and visualizations.

Features
WhatsApp chat parsing
Data preprocessing and cleaning
User activity analytics
Sentiment analysis
Interaction analysis
Topic detection
Word cloud generation
Time-based activity analysis
Streamlit dashboard visualization

Tech Stack
Python
Pandas
Matplotlib
Streamlit
TextBlob
WordCloud

Installation
Clone the repository:
git clone https://github.com/harshitavashisht24-png/whatsapp-chat-analyzer.git
Move into the project folder:
cd whatsapp-chat-analyzer
Install dependencies:
pip install -r requirements.txt

Input Format
Export WhatsApp group chat in .txt format
Place the exported chat file inside the project folder

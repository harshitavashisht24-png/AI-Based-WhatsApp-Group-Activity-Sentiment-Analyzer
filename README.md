# AI-Powered WhatsApp Behavioral Intelligence Dashboard

## Overview

This project is an AI-powered WhatsApp group chat analysis system that extracts meaningful conversational insights using NLP, Transformers, and Machine Learning techniques.

The system analyzes exported WhatsApp chats and generates:
- User activity analytics
- Sentiment analysis
- Emotion detection
- Semantic topic modeling
- Narrative detection
- Community detection
- AI-generated summaries
- Interaction intelligence

---

## Features

### Basic Analytics
- Total messages
- Most active users
- Message frequency analysis
- Word cloud generation

### AI/NLP Features
- Transformer-based sentiment analysis

## How to Run

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run AI Pipeline

```bash
python ai_pipeline.py
```

### Launch Dashboard

```bash
python -m streamlit run app.py
```
